Row vs Run

Is a Concept2 erg time faster than a running time over the same distance? Only at the very top. World-best runners leave the erg far behind, but rowing is faster for almost everyone else, and the weaker the athlete the bigger rowing's lead.

The crossover

How good do you need to be before running wins?

Within each sport, finish times sit close to a normal curve. Fitting that curve to each sport's five standards, and finding where the two meet, gives the percentile at which a run and an erg piece take the same time. Above it running is faster; below it the erg is. This extrapolates beyond the Elite (95th percentile) tables, so treat it as an estimate.

Why the gap closes

The erg squashes everyone together

How close each standard gets to world-best speed, averaged over 1 km to 10 km. A beginner on the erg is already about two-thirds of the way to world-record pace. A beginner runner is at about 40%.

ErgRunning

Power, not effort, sets erg pace

The Concept2 monitor turns power into pace with a cube root: watts = 2.80 ÷ (seconds per metre)³. Eight times the power only doubles the speed. Running speed rises roughly in line with the energy you put in. So differences in fitness show up about three times smaller on the erg. Body weight works the same way: the erg carries your weight for you, while a runner has to lift every kilogram.
